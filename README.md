# Антикоррупционный бот «Зачёт любой ценой?» (RU/TT)

## Файлы
- `bot.py` запуск, Telegram-обработчики (webhook на Render, polling локально)
- `game.py` логика квеста и режима «Правда или миф»
- `content.py` все тексты, сценарии, мифы, факты (правьте здесь)
- `certificate.py` генерация именного сертификата
- `fonts/` шрифты для сертификата (нужны обязательно)
- `render.yaml`, `requirements.txt`, `.python-version` настройки деплоя

## Деплой на Render
1. Загрузите содержимое папки в репозиторий GitHub (папка `fonts/` обязательна).
2. Render → New → Blueprint → выберите репозиторий (подхватит `render.yaml`).
   Либо New → Web Service: Build `pip install -r requirements.txt`, Start `python bot.py`, Plan Free.
3. В переменных окружения задайте `BOT_TOKEN` (токен от @BotFather) и `PYTHON_VERSION=3.12.8`.
4. После деплоя бот сам установит webhook по адресу сервиса. Откройте бота и отправьте /start.

Бесплатный сервис Render засыпает после ~15 минут без запросов, первый ответ после сна может прийти с задержкой.
Чтобы не засыпал, добавьте монитор (например, UptimeRobot) на `https://<ваш-сервис>.onrender.com/health` каждые 5 минут.
Прогресс игроков хранится в самих кнопках, поэтому сон и перезапуск ничего не ломают.

## Локальный запуск (для проверки)
    pip install -r requirements.txt
    BOT_TOKEN=... python bot.py
Локальный запуск использует polling и снимает webhook. После него перезапустите сервис на Render, чтобы webhook встал заново.
